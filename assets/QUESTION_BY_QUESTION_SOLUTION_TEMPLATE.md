# 阶段闸门：推进还是扩展研究

## 当前是否已经可交付

用一句话判断：

- 当前问题是否已经形成完整、可交给下一问使用的结果；
- 还存在哪些真实风险。

## 是否存在值得扩展研究的方向

如果没有，就明确写：

`NO_EXTENSION_RECOMMENDED`

并说明继续做为什么大概率只是堆实验。

如果有，必须填写：

- **研究问题：**
- **为什么值得研究：**
- **可能改变的决策：**
- **停止条件：**

四项任何一项无法回答，都不应继续扩展研究。

## 扩展研究结果

只能诚实记录以下之一：

- `MEANINGFUL_FINDING`
- `NO_MEANINGFUL_FINDING`
- `INCONCLUSIVE`

不要为了让扩展研究“有成果”制造规律、模型、创新点或结论。

# 聊天窗口摘要

本问完整研究结束后，默认只需要 2–6 句口语交流。

优先说明：

- 我刚完成了什么；
- 最重要的真实发现；
- 这个发现有什么用；
- 当前是否已经可以推进；
- 如果存在扩展方向，它为什么值得；
- 完整内容保存到哪个 Markdown。

每个真正有意义的研究结论都可以有适度、真实的情绪反馈，但不得无依据夸张。

例如：

```text
问题{k}这边我已经跑通了，这一轮结果挺关键：XXX。它意味着 XXX，所以后面问题{k+1}可以直接用 XXX。

我还看到一个可能值得再查一轮的点：XXX。如果你们想再冲一下我继续；如果更想推进，现在直接进下一问也没问题。完整过程我放进问题{k}_研究记录.md了。
```

如果没有扩展价值：

```text
这问现在已经比较稳了。我又检查了一轮，没看到值得继续深挖的方向，再跑更多东西大概率只是堆实验，我建议直接往下一问走。
```

示例只用于表达自然语气，不得机械套用。
