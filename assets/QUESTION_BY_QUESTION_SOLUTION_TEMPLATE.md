## Visual QA

进入论文或正式交付的图必须逐 panel 检查，而不是只看整张图“是否好看”。

至少检查：

- 每个 panel 的唯一结论/作用；
- Hero evidence 是否清楚；
- 数据是否完整，排除是否有记录；
- 配对结构是否被错误打散；
- 不确定性定义是否真实且一致；
- 中文、字体、负号是否正常；
- 标题、坐标轴、单位、图例是否完整；
- 是否遮挡、截断、重叠、空白；
- 论文尺寸下是否可读；
- 数据是否与对应 Run 和源文件一致；
- PNG/SVG 等输出是否实际存在且非空。

失败状态可能包括：

- `CHINESE_FONT_RENDERING_FAILED`
- `PAPER_FIGURE_READABILITY_FAILED`
- `VISUALIZATION_QA_FAILED`
- `OPTIMIZATION_CONVERGENCE_EVIDENCE_MISSING`

# 阶段闸门：推进还是扩展研究

当前问题必须先完整闭环，再讨论扩展研究。

若无真正值得研究的方向：

`NO_EXTENSION_RECOMMENDED`

若有，必须说明：研究问题、为什么值得、可能改变的决策、停止条件。

扩展研究结果只能诚实记录：

- `MEANINGFUL_FINDING`
- `NO_MEANINGFUL_FINDING`
- `INCONCLUSIVE`

不要为了让扩展研究“有成果”制造规律、模型、创新点、图表或结论。
