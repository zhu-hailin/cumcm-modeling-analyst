# 后续问题

# 全局验证

按题目适用情况完成：

- 单位、量纲、边界与约束检查；
- baseline 比较；
- 误差分析；
- 敏感性分析；
- 鲁棒性/压力场景；
- 替代模型；
- 随机算法重复性。

如果正式运行结果推翻第一阶段路线，应触发 `ROUTE_REOPEN_REQUIRED`，不得为了维持锁定路线硬解释。

---

# Python 与图表

- 最终采用方案必须有完整可运行 Python；
- 当前环境允许时实际运行关键入口；
- 保存关键图表、表格和中间结果；
- 图表默认由 Python 基于真实数据/模型结果生成；
- 用户未要求时禁止 AI 图片生成工具；
- 图表专业、简洁、论文可用，不堆叠无用信息。

---

# 教程与代码解析

对每个实际问题生成 `.md` 教程，与最终源码一致，包括模型思路、公式、数据、代码路径、关键函数、运行、输出、图表解释、验证和常见问题。

---
