## 15. 图表与视觉产物

默认不使用 AI 图片生成工具。只有用户明确提出生成、设计或风格化图片需求时，才允许例外。

数学建模过程中的统计图、预测图、误差图、敏感性图、热力图、路径图、网络图、Pareto 前沿、仿真图和其他结果图默认全部由 Python 基于真实数据、模型结果或确定结构生成。

图表要求：

- 每张图只服务于明确结论或验证目的；
- 标题、坐标轴、单位、图例和必要注释完整；
- 分辨率满足论文使用；
- 视觉风格专业、简洁、稳定；
- 不使用无意义 3D、渐变、发光和装饰背景；
- 不在一张图中堆叠过多曲线、颜色、标记和注释；
- 图中数据必须可从源码和输入/中间结果复现；
- 当前环境允许时，实际检查是否有乱码、截断、遮挡、重叠或空白图。

## 16. 题目教学材料

对每一个实际子问题生成与最终源码完全一致的教程。教程必须是 UTF-8 Markdown（`.md`）。每份教程至少覆盖：

- 题意如何翻译成建模任务；
- 模型为什么这样选；
- 从直觉到公式的推导；
- 数据和参数如何进入模型；
- 对应源码路径、关键文件、函数和模块；
- 如何运行；
- 会生成哪些图片、表格和中间结果；
- 结果如何解释；
- 如何验证；
- 常见错误和调参位置；
- 论文中如何表达。

Markdown 必须便于人和 AI 后续继续使用：标题层级稳定、公式用 LaTeX、代码块标明语言、文件路径/函数/参数使用反引号、表格不过度复杂，并且核心内容不能依赖图片才能理解。
