# AI 参考论文撰写与参考文献核验规范

## 1. 先区分两个概念

本 Skill 中以下两个概念必须严格区分，禁止混用：

### 参考论文

指 **AI 基于最终锁定建模路线、真实 Python 运行结果、最终图表和已核验参考文献，认真撰写的完整数学建模参考论文**。

它是最终交付成果的一部分，由 AI 自行编写，不是从互联网下载的他人论文，也不是“参考文献原文合集”。

最终放入：

```text
参考论文.zip
```

### 参考文献

指论文中用于支撑背景、方法、参数、数据、模型定义和验证方式的真实外部资料，例如期刊论文、学位论文、官方报告、标准、教材和权威数据来源。

参考文献的元数据、链接和用途必须真实核验；不得把它们与“AI 自己写的参考论文”混为一谈。

---

## 2. 参考论文.zip 的目标

`参考论文.zip` 必须包含 AI 自行撰写的最终参考论文，不得因为无法下载外部论文全文而留空。

默认至少生成：

```text
参考论文/
├── 数学建模参考论文.docx
└── 数学建模参考论文.pdf
```

如果用户提供官方论文模板、格式文件或排版要求，应优先基于该模板生成 Word 与 PDF，并使用更贴合题目的文件名，例如：

```text
A题_参考论文.docx
A题_参考论文.pdf
```

如果当前环境可以创建 DOCX/PDF，必须实际生成；不得只输出“论文结构”或空占位文件。

如果当前环境确实缺少某种文件生成能力，应先尽可能完成论文正文并明确反馈缺失能力，不能以“外部参考文献无法下载”为理由拒绝撰写论文。

---

## 3. 参考论文必须认真编写

参考论文不能只是把 `题目详解.zip` 中的教程复制粘贴，也不能只是第二阶段分析报告改一个标题。

它必须按照正式数学建模论文的叙事方式重新组织，做到：

- 问题导向明确；
- 模型链统一；
- 公式、变量、数据和结果互相对应；
- 每个关键结论都有实际计算或验证依据；
- 图表来自最终 Python 运行产物；
- 参考文献真实且链接经过核验；
- 不虚构任何数值、实验、图表、参数来源或引用。

论文正文至少应根据实际赛题包含：

1. 论文题目；
2. 摘要；
3. 关键词；
4. 问题重述；
5. 问题分析；
6. 模型假设；
7. 符号说明；
8. 数据说明与预处理；
9. 总体建模路线；
10. 各实际子问题的模型建立与求解；
11. 关键结果与图表解释；
12. 模型检验、误差分析、敏感性或鲁棒性分析；
13. 模型优点、局限与改进方向；
14. 最终结论；
15. 参考文献；
16. 必要附录或源码说明（若比赛格式适合）。

子问题数量按题面实际情况调整，不固定三问。

---

## 4. 论文必须与源码和结果一致

参考论文中的以下内容必须可以在最终交付中追溯：

- 使用的模型与 `源码.zip` 实际代码一致；
- 参数与实际运行参数一致；
- 数值结果与 Python 输出一致；
- 图表与 `源码.zip/.../outputs/figures/` 中的实际图表一致；
- 表格与实际输出表一致；
- 敏感性、鲁棒性或验证结论来自真实执行结果；
- 不得出现“论文写模型 A、源码跑模型 B”；
- 不得为了论文看起来完整而补造结果。

若论文写作阶段发现源码或结果存在冲突，应先修正模型、代码或结果，再生成最终论文。

---

## 5. 参考文献链接的强制真实性规则

参考论文中的参考文献必须真实，链接必须经过实际核验。

### 禁止

- 猜测或拼接 URL；
- 编造 DOI；
- 把搜索结果页地址伪装成论文地址；
- 把无法打开的链接写入论文；
- 声称“可下载”但实际没有验证下载入口；
- 用 AI 生成一个看似合理的链接；
- 因为论文题名真实，就自动认为某个链接真实。

### 正式写入论文前必须核验

对每一条带链接的参考文献，至少确认：

1. 题名、作者、年份与链接页面对应；
2. 页面能够实际打开；
3. 链接不是搜索摘要或无关二次转载；
4. 如果标记为“全文下载链接”，必须实际确认该链接可以取得对应论文全文，或明确进入真实可下载页面；
5. 下载到的文件或下载页面对应同一篇论文，而不是同名或错误文件；
6. 不把需要猜测参数、Token、临时会话的 URL 当成稳定下载链接。

优先顺序：

- 出版社/期刊/会议/高校/机构官方全文页面；
- DOI 对应正式页面中的合法全文入口；
- 作者或机构的公开仓储、学位论文库、开放获取仓储；
- 其他可核验且合法的正式下载来源。

---

## 6. “能打开”和“能下载”必须分开记录

文献账本至少区分：

- `PAGE_VERIFIED`：页面已实际打开并确认元数据；
- `DOWNLOAD_VERIFIED`：已进一步确认存在真实、可用的全文下载入口；
- `METADATA_ONLY`：只核验到元数据，不能声称全文可下载；
- `PAYWALLED`：真实但受付费墙限制；
- `BROKEN_LINK`：链接失效；
- `DOWNLOAD_UNVERIFIED`：页面存在，但未能可靠确认全文下载；
- `REJECTED`：来源不可靠或信息不一致。

只有真正通过对应核验的链接，才能在论文或文献账本中标成“可下载”。

---

## 7. 文献链接有问题时必须反馈用户

如果发现某条重要参考文献存在以下情况：

- 找不到稳定链接；
- 页面打不开；
- DOI 与题名不匹配；
- 下载链接失效；
- 只能查看摘要；
- 需要付费或机构权限；
- 下载文件与论文不匹配；
- 无法确认下载是否合法或稳定；

不得伪造替代链接，也不得静默跳过。

应：

1. 尽量继续寻找可靠替代来源；
2. 若找到等价且可核验的高质量来源，可替换并记录替换原因；
3. 若仍无法解决，明确向用户反馈具体问题；
4. 同时记录到：

```text
其他.zip/文献与来源/文献问题反馈.md
```

5. 若该文献是模型关键依据且没有可靠替代来源，应标记为证据缺口，并提醒用户决定是否提供原文或更换依据。

严格核验不能成为“参考论文.zip 为空”的理由。即使外部参考文献存在缺口，AI 仍应基于已完成的模型和已核验证据认真撰写参考论文，同时对证据缺口做诚实说明。

---

## 8. 参考文献在论文中的最低要求

正式参考文献列表只使用已经核验到足够程度的资料。

每条文献尽量记录：

- 作者；
- 题名；
- 期刊/会议/学校/机构；
- 年份；
- 卷期页码（只有真实核验后才写）；
- DOI（存在且已核验时）；
- 已核验链接；
- 核验日期。

如果用户要求参考文献附可下载链接，则只附 `DOWNLOAD_VERIFIED` 的链接；不能验证下载时必须反馈，不得伪造。

---

## 9. 最终论文质量检查

生成 Word/PDF 前检查：

- 是否真的由 AI 基于本次赛题重新撰写，而不是外部论文合集；
- 是否覆盖所有实际子问题；
- 是否使用最终锁定路线；
- 结果是否来自实际 Python 执行；
- 图表是否来自最终 Python 输出；
- 公式和符号是否一致；
- 是否存在编造的数值、模型效果或实验结论；
- 是否存在编造题名、作者、DOI 或链接；
- 参考文献链接是否经过实际打开核验；
- 被标成可下载的链接是否经过下载可用性核验；
- 发现链接问题时是否已反馈用户并记录；
- Word 与 PDF 内容是否一致；
- 用户提供论文模板时是否按模板排版。

只有论文内容和参考文献核验均达到要求后，才进入 `FINAL_DELIVERY`。
