# 图前证据契约：先决定“这张图要证明什么”

本规范借鉴成熟科研绘图工作流中的 evidence-first 思想，但适配数学建模竞赛，而不是照搬期刊投稿规则。

## 核心原则

正式图不是“数据的装饰”，而是一个可核验的视觉论证。

在写绘图代码前，先回答：

1. **核心结论**：这张图必须让读者看懂什么？
2. **证据层级**：哪些是主结果，哪些是验证/稳健性，哪些只是背景？
3. **每个 panel 的唯一任务**：每个子图分别回答什么问题？
4. **源数据**：每个 panel 来自哪个真实文件/表/数组？
5. **不确定性**：是否存在误差、区间、随机重复、场景范围需要展示？
6. **审查风险**：评阅者最可能质疑什么？图能否回应？

推荐在问题级研究记录中先写一个简短契约：

```text
核心结论：
图的角色：结果 / 机制解释 / 验证 / 鲁棒性 / 决策
主证据：
辅助证据：
panel a：
panel b：
panel c：
源数据：
不确定性定义：
评阅风险：
最终论文候选：是 / 否
```

## 1. Claim-first，而不是 Table-first

禁止“一个 CSV 一张图”“一个 DataFrame 一张图”的机械做法。

先按结论组织证据：

- 多个表可能共同支撑一张复合图；
- 同一个结果表可能被不同图从不同角度解释；
- 若两张图只是重复表达同一结论，应合并或删除。

判断规则：

> 遮住某个 panel 后，如果整张图的论证几乎不受影响，该 panel 很可能应该删除或合并。

## 2. Hero evidence 与 supporting evidence

复合图不要求所有 panel 等大、等亮、等重要。

优先明确：

- **Hero evidence**：最直接回答问题、决定结论的主结果；
- **Validation evidence**：误差、残差、敏感性、收敛、鲁棒性等；
- **Context evidence**：必要的数据结构、基线、局部解释。

主结果应该在布局、尺寸和视觉层级上更突出；验证图不应喧宾夺主。

## 3. 数学建模常用证据链

### 预测

`原始结构/数据 → 最终预测 → 误差/残差 → 稳健性/区间`

### 优化

`问题结构/网络 → 最优方案 → 收敛/最优性或 baseline → 参数/场景敏感性`

### 综合评价

`指标结构 → 最终排序/得分 → 权重或方法敏感性 → 稳健排序`

### 聚类

`数据结构 → 聚类结果 → 质量指标 → 中心/类别解释`

### 仿真

`场景/参数 → 输出分布 → 区间/风险 → 收敛/重复性`

不要求机械补齐所有环节，只保留真正支撑当前结论的证据。

## 4. 数据完整性门

不得为了图更好看或模板更容易套用而静默：

- 删除行；
- 删除类别；
- 只挑表现好的时间段；
- 只画部分模型；
- 忽略异常场景；
- 把失败种子从统计中剔除；
- 只展示有利结果。

任何科学/数学上合理的排除，都必须记录：

| 对象 | 排除前数量 | 排除后数量 | 规则 | 理由 | 对结论影响 |
|---|---:|---:|---|---|---|

原始数据必须保留。

如果排除只是“为了让图更漂亮”，不允许执行。

## 5. 配对/重复结构优先保持

若同一对象在不同模型、场景、时间或参数下重复测量，不要只画彼此独立的边缘分布而丢掉配对关系。

例如：

- 同一地区不同方案；
- 同一车辆不同策略；
- 同一测试集不同模型；
- 同一随机种子不同算法；
- 同一参数组扰动前后。

必要时使用 paired difference、变化量或相连点图，让“同一对象的改变”可见。

## 6. 不确定性必须定义一致

同一组可比较图中，若展示误差带/误差棒，必须统一其定义，例如：

- mean ± SD；
- median + IQR；
- 95% CI；
- 多随机种子均值 ± SD；
- Monte Carlo 分位数区间。

禁止 panel A 用 SD、panel B 用 SE，但正文仍笼统说“误差范围”。

无法计算或没有重复实验时，不得伪造误差条。

## 7. 图内术语与语义保持一致

同一模型、方案、地区、车辆、场景在所有正式图中应保持：

- 名称一致；
- 缩写一致；
- 大小写一致；
- 颜色语义尽量一致；
- marker/line style 语义尽量一致；
- 单位一致。

不要对 `XGBoost`、`ARIMA`、`NSGA-II`、`TOPSIS` 等名称做错误自动大小写转换。

## 8. 论文图前检查

每张 A/B 级论文候选图至少要能回答：

- 它支撑哪个原题要求或结论？
- 最重要的 panel 是哪个？
- 每个 panel 是否有唯一作用？
- 是否存在重复 panel？
- 数据是否完整？
- 不确定性是否真实且定义一致？
- 是否保留了重要配对结构？
- 是否存在选择性展示？
- 是否能追到真实源数据和生成代码？

无法回答时，不应直接进入论文。
