# 建模路线选择地图

先判断任务、数据和约束，再选择方法。

## 综合评价与排序

候选：标准化 + 熵权/CRITIC + TOPSIS；AHP 与客观权重组合；PCA/因子分析；模糊评价；DEA；多属性决策。

检查指标重复、正负向处理、权重主观性、排序稳定性和结论导向选指标。

## 回归、解释与影响分析

候选：线性/广义线性、非线性回归、面板模型、分位数回归、生存分析、贝叶斯层次模型、树模型解释、因果推断（仅识别条件成立时）。

检查相关与因果、多重共线性、内生性、残差、泄漏和实际意义。

## 预测

候选：朴素基线、趋势、ARIMA/SARIMA、ETS、状态空间、灰色预测、回归、树集成、神经网络、组合预测和区间预测。

检查时间切分、滚动预测、季节性、结构突变、区间、基线和指标。

## 分类、聚类与识别

候选：Logistic、LDA/QDA、SVM、树模型、k-means、层次聚类、DBSCAN、GMM、PCA、异常检测、深度学习。

检查标签、类别不平衡、特征泄漏、参数、可解释性和评价指标。

## 数学规划与调度

候选：线性/整数/混合整数规划、非线性规划、动态规划、网络流、匹配、最短路、VRP、选址、排班、多目标、随机规划、鲁棒优化、启发式求解器。

检查变量和约束是否来自题面、不可行情况、规模、最优性界、目标权衡和可执行性。

## 机理与动态系统

候选：常/偏微分方程、差分方程、系统动力学、马尔可夫链、传播、排队、库存、状态空间。

检查物理意义、初边值、参数可识别性、稳定性、数值误差和校准。

## 随机与仿真

候选：蒙特卡洛、离散事件、Agent-based、排队仿真、压力测试。

检查分布来源、重复次数、收敛、置信区间、规则、随机种子和外部对照。

## 图与网络

候选：最短路、最大流、最小费用流、中心性、社群、生成树、TSP/VRP、传播和时变网络。

检查节点、边、权重、有向性、连通性和指标现实含义。

## 不确定性与决策

候选：情景分析、敏感性、Bootstrap、贝叶斯决策、鲁棒优化、随机规划、风险度量和多准则决策。

检查不确定性来源、概率依据、保守性、决策稳定性和切换阈值。

## 组合原则

常见组合：

- 评价 → 预测 → 优化
- 机理 → 参数估计 → 情景仿真
- 数据描述 → 统计解释 → 决策
- 基线预测 → 增强预测 → 鲁棒决策
- 优化模型 → 启发式求解 → 敏感性验证

删除某模型不影响结论时，该模型大概率是装饰。
