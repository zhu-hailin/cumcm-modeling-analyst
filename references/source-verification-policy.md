# 文献与数据来源核验政策

## 目标

核验两个不同问题：

1. **来源是否真实、是否真正支持当前主张；**
2. **全文/下载入口处于什么访问状态。**

这两件事不能混为一谈。不能因为没有公开下载链接就否定一篇已经真实取得并读过的文献，也不能因为有一个能下载的 PDF 就默认它可靠或支持当前结论。

---

## 1. 来源优先级

### S 级

- 竞赛官方、组委会、中国工业与应用数学学会正式文件；
- 政府、法定统计、国家/行业标准；
- 题目指定数据；
- 期刊/出版社/学位授予单位官方页面；
- DOI 注册记录和正式数据库元数据。

### A 级

- 正式同行评议论文；
- 中文核心、CSSCI、CSCD、EI、SCI 等可核验研究；
- 正式教材、专著、学位论文、会议论文集。

### B 级

- 政府/行业技术报告；
- 高校、科研机构公开报告；
- 企业正式白皮书；
- 可核验的竞赛优秀论文和赛题讲评。

### C 级

博客、论坛、公众号、知乎、小红书、CSDN、个人网盘、搜索摘要和二次转载。可用于发现线索，但关键模型、参数或现实结论应继续追原始来源。

---

## 2. 正式使用前核验什么

尽可能确认：

- 题名、作者、年份和来源；
- 卷期页码、DOI/ISBN/数据库记录（存在时）；
- 内容与当前赛题的实际相关性；
- 当前真正读到了全文、关键章节、摘要还是只有元数据；
- 是否存在撤稿、勘误或版本差异；
- 当前主张具体由哪部分内容支持。

不得猜 DOI、卷期页码、URL 或作者信息。

**模型定义、关键参数、关键现实数据和会改变路线的学术主张，必须达到足以支持该具体主张的阅读深度。** 只看搜索摘要或元数据不能提取全文级方法细节。

---

## 3. 链接真实性必须实际打开

任何准备进入来源账本或论文的链接，都要实际打开并核对页面内容。

禁止：

- 根据 DOI 结构猜 URL；
- 根据题名拼网页地址；
- 用搜索结果页当正式论文链接；
- 用题名/作者/年份不匹配的页面；
- 仅凭搜索摘要写“链接有效”；
- 生成一个看起来像真的地址。

至少确认页面可访问、元数据匹配且来源合理。

---

## 4. 访问状态与证据状态分开记录

链接/页面访问状态：

```text
PAGE_VERIFIED          # 页面已打开且元数据匹配
DOWNLOAD_VERIFIED      # 进一步确认稳定、真实的全文下载入口
METADATA_ONLY          # 只核验到元数据
PAYWALLED              # 页面真实但全文需付费/机构权限
DOWNLOAD_UNVERIFIED    # 页面真实，但未确认可复现全文下载
BROKEN_LINK            # 链接失效
REJECTED               # 来源或内容不匹配
```

阅读/证据状态可以另记：

```text
FULLTEXT_READ           # 全文已实际读取
KEY_SECTIONS_READ       # 与当前主张相关的关键章节已读取
ABSTRACT_ONLY           # 只读摘要
METADATA_ONLY           # 只有元数据
```

例如：用户上传了一篇合法取得的全文并已完整读取，即使出版社网页为 `PAYWALLED`，仍可以 `FULLTEXT_READ + PAGE_VERIFIED/PAYWALLED` 使用它作为真实学术依据；不能把它描述成“公开可下载”。

---

## 5. 什么时候必须是 DOWNLOAD_VERIFIED

只有当你准备声称：

- “这里可以直接下载全文”；
- “已提供可下载链接”；
- 内部资料包需要一个可复现的公开全文下载入口；

才要求：

```text
DOWNLOAD_VERIFIED
```

最终参考论文**不要求每篇被引用文献都有公开下载链接**。论文可以使用已经核验的 DOI、出版社 landing page 或正式数据库页面作为定位信息；关键是文献真实、引用内容确实读过并支持当前主张。

如果论文中专门提供“下载链接”，该链接必须达到 `DOWNLOAD_VERIFIED`。

---

## 6. 全文无法公开下载时怎么处理

如果文献很重要但找不到公开全文：

1. 检查出版社、作者/机构仓储、开放获取仓储、学位论文官方库；
2. 用户已经提供全文时，直接核验本地全文并记录来源；
3. 有机构访问权限时，按实际访问状态记录，不伪装成公开下载；
4. 仍只有摘要/元数据时，不能据此提取关键公式、参数或全文级结论；
5. 如果缺失全文会改变当前模型选择或结论，才升级为需要用户介入的证据缺口。

不要因为普通“下载便利性”问题频繁打断建模。

---

## 7. 数据来源还要核验口径

关键现实数据不仅要有链接，还要检查：

- 发布机构；
- 发布时间和统计期；
- 对象、地域与覆盖范围；
- 指标定义和单位；
- 累计值/当期值；
- 自然年/财年/航季/月度等时间口径；
- 子范围和修订值；
- 网页、表格与下载附件是否一致。

同名指标口径不一致时不能直接拼接。

---

## 8. 原始来源原则

- 模型定义优先追原始论文或权威教材；
- 参数追标准、测量或正式研究；
- 现实数据追官方原始数据；
- 综述用于全局理解，不替代关键原始证据；
- 中国现实场景优先寻找本土官方统计、标准、对象官网和本土应用研究；经典算法可引用高质量国际原始文献。

中文优先不是质量豁免，也不设置机械中外文献比例。

---

## 9. 记录方式

对会影响模型、参数、验证、图表或论文的来源至少记录：

| 字段 | 内容 |
|---|---|
| 来源 / 数据名称 | 题名或指标 |
| 发布者 / 作者 | |
| 原始页面 / DOI | 实际打开的定位页面 |
| 访问状态 | PAGE_VERIFIED / ... |
| 阅读状态 | FULLTEXT_READ / ... |
| 时间、空间、单位 / 版本 | 适用时 |
| 本地文件 | 适用时 |
| 当前题用途 | 哪个问题、参数、模型或结论 |
| 风险 / 口径差异 | |

同一事实只维护一份权威记录，教程和论文引用它，不要多份表格手抄同一 URL 与访问状态。

---

## 10. 旧题盲测边界

盲测冻结前可以查通用理论、官方现实数据和软件文档，但查询不能使用足以定位历史答案的年份题号、完整题名、题面原句、附件名或特殊数据组合。

意外命中历史完整答案时停止继续读取并标记 `ANSWER_LEAKAGE_DETECTED`。

---

## 11. 底线

- 不能确认真实性时明确说未核验；
- 没读到的内容不假装读过；
- 不编 DOI、URL、全文状态或下载状态；
- “可引用”和“可公开下载”是两个不同判断；
- 下载问题只有在会改变建模决策、正式引用证据或用户明确要求下载时才升级为阻塞问题。
