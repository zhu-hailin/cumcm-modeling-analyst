# 文献与数据来源核验政策

## 1. 来源优先级

### S 级

- 竞赛组委会、官方网站、中国工业与应用数学学会正式文件；
- 中国政府部门、国家统计局、部委、地方政府和法定统计公报；
- 国家或行业标准；
- 期刊、出版社、学位授予单位官方页面；
- DOI 注册记录和正式数据库元数据；
- 题目指定数据。

### A 级

- 中文核心、CSSCI、CSCD、EI、SCI 等正式论文；
- 知网、万方、维普可核验记录；
- 正式教材、专著；
- 正式学位论文；
- 正式会议论文集。

### B 级

- 政府或行业技术报告；
- 高校、科研机构公开报告；
- 企业正式白皮书；
- 可核验的国赛优秀论文、赛题讲评或后续研究成果。

### C 级

博客、论坛、公众号、知乎、小红书、CSDN、个人网盘、搜索摘要和二次转载。只能作检索线索，不得作为关键模型、参数或结论的唯一证据。

## 2. 真实性检查

正式引用前尽可能确认：

- 题名；
- 作者；
- 年份；
- 来源；
- 卷期页码；
- DOI/ISBN/数据库记录；
- 内容与当前赛题的实际相关性；
- 页面访问状态；
- 是否存在撤稿、勘误或版本问题。

不得猜卷期页码、DOI 或 URL。

## 3. 链接真实性：必须实际打开

任何准备写入最终参考论文或文献账本的链接，都必须由 AI 实际打开并核对页面内容。

禁止：

- 根据 DOI 结构猜 URL；
- 根据题名拼接网页地址；
- 使用搜索结果页作为正式论文链接；
- 使用与题名/作者/年份不匹配的页面；
- 使用无法访问的链接；
- 仅凭搜索摘要就判断链接有效；
- 生成一个“看起来像真的”链接。

至少确认：

1. 页面实际可打开；
2. 页面题名、作者和年份与目标文献对应；
3. 页面来自合理的正式来源；
4. 页面不是无关转载、搜索摘要或错误同名文献。

## 4. “可打开”与“可下载”必须严格区分

统一使用以下状态：

- `PAGE_VERIFIED`：页面已实际打开，元数据匹配；
- `DOWNLOAD_VERIFIED`：在 `PAGE_VERIFIED` 基础上，进一步确认存在真实、可用的全文下载入口；
- `METADATA_ONLY`：只核验到元数据，不能声称拿到全文；
- `PAYWALLED`：文献真实，但需要付费或机构权限；
- `DOWNLOAD_UNVERIFIED`：页面存在，但未能可靠确认全文下载；
- `BROKEN_LINK`：链接失效或无法打开；
- `REJECTED`：来源不可靠、信息不匹配或不应采用。

**只有 `DOWNLOAD_VERIFIED` 才能写“可下载”。**

如果用户要求“链接必须能直接下载”，则最终论文和交付清单中只能提供经过 `DOWNLOAD_VERIFIED` 的链接。

## 5. 下载核验

如果某链接被描述为全文下载链接，必须确认：

- 下载入口真实存在；
- 指向目标论文，而非同名错误文件；
- 下载文件/页面对应的作者、题名与目标文献一致；
- 链接不是依赖临时 Token、猜测参数或不可复现会话才能访问的伪稳定地址；
- 当前环境能够合理确认其为合法、正式或公开可获取来源。

优先使用：

- 出版社/期刊/会议/高校/机构官方全文入口；
- DOI 正式页面中提供的合法全文入口；
- 作者/机构公开仓储；
- 学位论文官方库；
- 可靠开放获取仓储。

## 6. 链接失败时必须反馈用户

出现以下情况之一时，不得伪造替代链接，也不得静默忽略：

- 页面打不开；
- DOI 与文献不匹配；
- 下载入口失效；
- 只能查看摘要；
- 需要付费或机构权限；
- 文件下载后与目标文献不匹配；
- 无法确认下载稳定性或合法来源。

处理顺序：

1. 尝试寻找等价、可靠的替代来源；
2. 若找到，记录替换原因；
3. 若仍无法解决，明确反馈用户；
4. 记录到 `其他.zip/文献与来源/文献问题反馈.md`；
5. 如果该文献是关键模型依据且无替代证据，标为证据缺口，请用户决定是否提供原文或更换依据。

## 7. 原始来源原则

- 模型定义追溯原始论文或权威教材；
- 参数追溯测量、标准或正式研究；
- 数据追溯官方原始数据；
- 综述用于全局，不替代关键原始证据。

## 8. 中文优先

顺序：

1. 竞赛官方文件与优秀论文；
2. 中国政府和官方统计数据；
3. 中文核心及正式学位论文；
4. 中文教材和专著；
5. 国际原始方法论文；
6. 高质量国际应用论文。

中文优先不是质量豁免。

## 9. 数据来源记录

记录：数据集、发布机构、下载日期、时间/空间范围、字段、单位、更新频率、许可、清洗规则和口径差异。

## 10. 最终参考文献输出

最终参考论文中的参考文献只使用达到足够核验等级的资料。

每条尽量记录：

- 作者；
- 题名；
- 来源；
- 年份；
- 卷期页码（核验后才写）；
- DOI（存在且核验后才写）；
- 已核验链接；
- 链接状态；
- 核验日期；
- 对本题具体用途。

如果不能确认下载，不得写“下载地址”。

## 11. 与“参考论文”的关系

本文件约束的是 **外部参考文献和数据来源**。

`参考论文.zip` 中的成果论文由 AI 针对本次赛题自行撰写，详见 [reference-paper-writing.md](reference-paper-writing.md)。

外部参考文献存在下载问题，不等于不能撰写最终参考论文。AI 仍应基于已完成模型、真实结果和已核验证据完成论文，并对证据缺口诚实说明。
