# 文献与数据来源核验政策

## 来源优先级

### S 级

- 竞赛组委会、官方网站、中国工业与应用数学学会正式文件；
- 中国政府部门、国家统计局、部委、地方政府和法定统计公报；
- 国家或行业标准；
- 期刊、出版社、学位授予单位官方页面；
- DOI 注册记录和正式数据库元数据；
- 题目指定数据。

### A 级

- 中文核心、CSSCI、CSCD、EI、SCI 等正式论文；
- 知网、万方、维普可核验记录；
- 正式教材、专著；
- 正式学位论文；
- 正式会议论文集。

### B 级

- 政府或行业技术报告；
- 高校、科研机构公开报告；
- 企业正式白皮书；
- 可核验的国赛优秀论文、赛题讲评或后续研究成果。

### C 级

博客、论坛、公众号、知乎、小红书、CSDN、个人网盘、搜索摘要和二次转载。只能作检索线索，不得作为关键模型、参数或结论的唯一证据。

## 真实性检查

正式推荐前尽可能确认题名、作者、年份、来源、卷期页码、DOI/ISBN/数据库记录、内容、访问层级、撤稿或勘误。失败时写：

> 待核验，不得直接写入正式参考文献。

不得猜卷期页码或 DOI。

## 原始来源原则

模型定义追溯原始论文或权威教材；参数追溯测量、标准或正式研究；数据追溯官方原始数据；综述用于全局，不替代关键原始证据。

## 中文优先

顺序：

1. 竞赛官方文件与优秀论文；
2. 中国政府和官方统计数据；
3. 中文核心及正式学位论文；
4. 中文教材和专著；
5. 国际原始方法论文；
6. 高质量国际应用论文。

中文优先不是质量豁免。

## 检索式

每个子问题构造：

- 中文主题词 + 任务词 + 方法词；
- 中文主题词 + 数据/参数/指标；
- 英文主题词 + task + method；
- 方法名 + application + validation；
- 背景 + 国家/地区 + report/statistics；
- 相似赛题年份 + 题号 + 优秀论文/赛题讲评。

## 数据来源记录

记录数据集、发布机构、下载日期、时间空间范围、字段单位、更新频率、许可、清洗、口径差异。

## 引用输出

分为：

- 已核验，可正式引用；
- 已核验，仅适合作背景；
- 待获取全文；
- 待核验元数据；
- 不推荐引用。
