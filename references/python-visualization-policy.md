# nature-figure 接入与赛中 Python 制图

此文件保留旧路径供现有链接使用，但不再维护一套自有绘图样式、布局或导出规范。论文图表的设计、配色、排版、导出和视觉 QA 统一使用 [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills) 中的 [nature-figure/SKILL.md](https://github.com/Yuan1z0825/nature-skills/blob/main/skills/nature-figure/SKILL.md)。本文件只连接比赛进度、证据来源和交付职责。

## 1. 找到并加载真正的技能

本版核对版本：nature-figure 2.8.0，仓库 commit `9e2d90e2171a61dc0ae072e43e8d16e3fc73572f`。在项目说明记录实际使用的来源、版本/commit 和可读取入口；赛中复用同一版本，不因每次画图自动更新依赖。

1. 优先查找已安装或项目已有的、来自上述仓库的完整 `nature-figure` 目录。仅同名不能证明来源一致。
2. 读取其 `SKILL.md`、`manifest.yaml`、manifest 的 `always_load` 及 Python fragment；按图表任务加载所需参考。不要只复制入口而漏掉脚本、素材和参考；用到 `../nature-shared/` 时保留同级共享目录。
3. 缺少依赖时，在当前环境允许的工作区依赖位置获取该仓库并使用完整技能目录，不覆盖队伍已有技能。没有获取/运行能力时，说明具体缺口并继续独立建模和写作，不声称已使用该技能，也不偷偷回退到旧绘图程序规范。
4. Python 已由本项目工作流明确选择，无需再问 Python 还是 R；仅加载 Python 分支。使用上游 `nature_figure_backend.py set python` 时，将 `NATURE_FIGURE_CONFIG` 指向项目本地配置，避免改变其他项目偏好。

可复现依赖示例（在项目选定的依赖目录执行；已有完整副本时不重复克隆）：

```bash
git clone https://github.com/Yuan1z0825/nature-skills.git
git -C nature-skills checkout 9e2d90e2171a61dc0ae072e43e8d16e3fc73572f
```

安装所选技能的运行依赖不等于已经生成或验收图表。按上游实际文档执行源码检查、PDF 文字与碰撞检查、多面板对齐（适用时）及实际尺寸视觉检查，并保留真实报告；工具缺失或无法审计不能标成通过。

## 2. 在每问过程中生成，不把制图留到最后

| 阶段 | 当时完成的图表工作 |
|---|---|
| 读题与路线研究 | 识别要解释的问题及需要的证据；有真实 EDA/小实验结果时，用 Python 形成必要的探索图表 |
| 当前问已确认、实验正在进行 | 代码手随运行输出结果表和候选图，建模手检查科学含义，论文手反馈论证位置与可读性 |
| 当前问结果已经核验 | 用同一来源更新论文图表、图注和正文锚点，完成 nature-figure 要求的 QA；阶段结果明确标记其状态 |
| 赛末整稿 | 核对已有图表的版本、编号、尺寸、引用和样式；不得将所有图表的首次生成推迟到此时 |

一开始不必把每张探索图都当终稿；但准备进入论文的图在本问内就应生成、检查并迭代。新证据确实需要新增图时仍可新增，不能为了截止时间伪造数据或跳过必要验证。无需图表的简单结果记录 `FIGURE_NOT_NEEDED`，不设数量配额。

论文图、方法结构图和结果表均通过 Python 代码从真实数据、计算或已确认模型定义生成。结果表同时保留可编辑数据/表格，不把截图作为唯一结果。上游支持 R 或 AI 示意图并不替代这里明确的 Python 路径；不要自动开启付费图像 API。借用其图表方法，不套用 Nature 期刊专属篇幅、语言或投稿配额。

## 3. 每张图表下都有解释

图题/表题不能替代说明。每张论文图下方写解释性图注，每张表下方写表注，至少覆盖：

- 展示什么：对象、时间/样本范围、指标、单位和必要的比较条件；
- 反映什么：主要趋势、差异、机制或权衡；
- 支持什么判断：与本问模型选择、结果解释或结论的关系；
- 必要边界：是否仅为样本内现象、对照实验、条件性结论或示意。

图内文字保持简洁，长解释放图注或正文。不能将相关性写成因果，不能从一张图推断尚未验证的最优性；多面板图对各面板有可对应解释。样本图注只提供写法，具体结论必须从实际证据读取。

## 4. 证据接口与角色分工

- 建模手：定义图表回答的问题、比较对象、单位、误差含义及可以声称的结论。
- 代码手：负责 Python 生成代码、源数据/Run 对应、实际执行、导出和检查报告。
- 论文手：负责图表在论证中的位置、下方说明及正文解释。
- 主 agent：核对同一版本并验收；单代理模式自行覆盖以上职责。

数据图沿用 `源数据 + Run + Python 脚本`；方法图沿用 `已确认模型版本 + Python 脚本`，Run 可注明不适用。用既有证据蓝图记录图表角色、来源和正文位置，不另建重复台账。改数据或计算逻辑时重跑受影响成果；只改样式时重绘并按 nature-figure 重新 QA，不重算所有模型。

`scripts/figure_utils.py` 仅保留供旧项目兼容，不是 v12 新图的样式或 QA 入口，其回归测试通过也不代表 nature-figure 图件已验收。
