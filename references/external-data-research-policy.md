# 外部真实数据与本土资料规范

## 目标

题面未提供、但模型依赖的现实事实、统计量、行业参数、政策口径或运营数据，必须优先从真实、可核验来源取得。

> **宁可明确缺数据，也不能编数据。**

编造外部观测值时：

```text
FABRICATED_EXTERNAL_DATA
```

立即停止使用，并回溯相关模型、Run、图表和论文结论。

---

## 1. 什么时候必须主动检索

例如：

- 机场起降架次、吞吐量、航班量和容量；
- 人口、GDP、价格、销量和交通流；
- 气象、环境、能源、医疗和教育统计；
- 设备性能、工程参数和行业阈值；
- 政策、标准、收费规则和排放因子；
- 用于校准、验证、边界和敏感性范围的历史数据。

附件没有给出浦东机场起降数据时，不能自行假设日均架次、增长率或峰值容量，应主动检索官方或对象来源。

---

## 2. 来源优先级

中国现实场景默认：

1. 中国政府、法定统计、国家/行业标准；
2. 现实对象官网、年报、公告和开放数据；
3. 国内行业协会、高校、科研院所和可核验中文研究；
4. 国际组织、国外政府、国际权威数据库和高质量论文；
5. 新闻、博客、论坛和自媒体只作线索，关键数据继续追原始来源。

方法论和经典算法可以大量引用高质量国际文献；中国政策、统计口径、行业参数、地区背景和现实运营数据应主动寻找本土证据。

不设置机械中外文献比例，也不为凑数量加入无关资料。

---

## 3. 严禁的补数据方式

禁止：

- 凭常识填一个“合理值”；
- 把模型假设包装成现实统计；
- 只看搜索摘要就抄无法核验的数字；
- 用其他地区、对象或年份冒充当前对象；
- 把行业范围中点当成观测值；
- 自行制造增长率、缺失年份、样本量或分布；
- 为了让代码运行偷偷生成现实观测；
- 插值、估计、外推或仿真后不说明性质。

数据类型必须区分：

```text
OBSERVED_EXTERNAL
INTERPOLATED
EXTRAPOLATED
MODEL_ESTIMATED
ASSUMED
SIMULATED
```

只有 `OBSERVED_EXTERNAL` 可以不加限定地称为外部观测数据。

---

## 4. 数值之外还要核验口径

每项关键数据检查：

- 发布机构和原始页面/文件；
- 发布时间和统计期；
- 对象、地域与覆盖范围；
- 指标定义和单位；
- 累计值还是当期值；
- 自然年、财年、航季还是月度；
- 国内/国际、客运/货运等子口径；
- 是否存在修订值；
- 网页、表格与下载附件是否一致。

同名指标口径不一致时不能直接拼接。

---

## 5. Codex 保存与追溯

```text
01_data/external/       # 下载的外部原始文件
01_data/processed/      # 清洗、合并和单位统一后的数据
07_references/websites.md
07_references/notes.md
07_references/papers/
```

外部原文件不写入 `01_data/raw/` 冒充题目数据，也不被清洗脚本覆盖。

每个会影响模型、参数、验证、图表或论文的数据至少记录：

| 字段 | 内容 |
|---|---|
| 数据名称与对象 | 指标、地区/机构/设备 |
| 发布机构与 URL | 实际核验的原始来源 |
| 获取日期与范围 | 时间、空间和样本范围 |
| 原始/使用单位 | 含换算 |
| 统计口径 | 定义、累计/当期、子范围 |
| 本地原文件 | `01_data/external/` 路径 |
| 清洗后文件 | `01_data/processed/` 路径 |
| 处理脚本 | 对应中文源码 |
| 数据处理 | 清洗、插值、外推或估计 |
| 使用位置 | 问题、模型、图表和 Run ID |
| 数据类型 | OBSERVED_EXTERNAL / ... |

---

## 6. 找不到可靠数据

经过合理搜索仍找不到时：

1. 明确缺什么；
2. 说明搜索过哪些权威渠道；
3. 讨论用户补充、可核验代理变量、区间/敏感性分析或改模型；
4. 必须假设时标为 `ASSUMED`，说明影响范围；
5. 不因为任务需要完成而制造数值。

缺口会改变路线时，在当前问题正式实现前与用户讨论。

---

## 7. 与旧题盲测兼容

`BLIND_BENCHMARK_MODE` 允许搜索真实官方数据、通用参数、原始理论和库文档，但查询不能使用足以定位历史答案的年份题号、完整题名、题面原句、附件名和特殊数据组合。

> **禁止搜答案，不禁止查现实。**

意外命中该题历史论文或完整解答时，按 `core-workflow.md` 标记 `ANSWER_LEAKAGE_DETECTED` 并停止继续读取。

---

## 8. 与来源核验的关系

本文件决定何时必须找现实数据和真实性底线；`source-verification-policy.md` 决定网页、文件、DOI、全文和下载状态如何核验。

```text
现实数据缺口
→ 检索权威来源
→ 实际打开并核验口径
→ 保存外部原文件
→ 清洗结果另存
→ 记录来源与处理
→ 模型和 Run 使用
→ 论文可追溯
```

任何关键现实数据无法说明来源、口径和处理时，不得作为已验证最终结论。
