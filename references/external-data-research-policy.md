# 外部真实数据与本土资料检索规范

## 目标

数学建模中只要结论依赖现实世界中的外部事实、统计量、行业指标、政策口径或其他题面未直接提供的数据，AI 默认应优先联网寻找真实、可核验的来源，而不是凭常识、经验范围或“看起来合理”的数字补齐。

找不到可靠数据时，应明确记录数据缺口、可替代方案和对模型的影响。**宁可缺数据，也不能编数据。**

严重违规状态：

```text
FABRICATED_EXTERNAL_DATA
```

出现后必须停止使用该数据，回溯相关模型、结果、图表和论文结论，并重新建立证据链。

---

# 1. 哪些情况必须主动联网找数据

只要题目或模型需要现实世界中的量，而题面/附件没有可靠给出，就应主动检索。例如：

- 机场起降架次、旅客吞吐量、航班量、航线结构；
- 人口、GDP、就业、价格、销量、交通流量；
- 气象、环境、能源、物流、医疗、教育等统计；
- 设备性能、工程参数、行业阈值；
- 政策、标准、收费标准、排放因子；
- 历史时间序列；
- 某地区、企业、机场、港口、景区等现实实体的运营数据；
- 为校准、验证、边界检查或敏感性范围提供依据的数据。

例如题目涉及“浦东机场起降数据”，而附件没有完整给出时，AI 不应自行假设日均架次、年增长率或峰值容量，应主动从权威公开来源检索。

---

# 2. 数据来源优先级

中国赛题或中国现实场景默认优先：

1. **中国官方 / 法定统计来源**
   - 国家统计局及国家数据；
   - 国务院部门、民航局、交通运输部、生态环境部等；
   - 省市政府、统计局、行业主管部门；
   - 统计年鉴、统计公报、政府公开数据平台；
   - 国家标准、行业标准和正式政策文件。
2. **现实对象的官方来源**
   - 机场、港口、企业、交易所、运营机构官网；
   - 年报、社会责任报告、运营快报、官方公告；
   - 官方开放数据接口或下载文件。
3. **中国权威行业 / 科研机构**
   - 行业协会；
   - 高校、科研院所正式报告；
   - 中文核心、CSCD、CSSCI、学位论文等可核验资料。
4. **国际权威来源**
   - 国际组织、国外政府机构、国际行业数据库；
   - 高质量国际论文和数据库。
5. **二次来源**
   - 新闻、博客、论坛、自媒体等仅作线索，关键数据必须继续追原始来源。

来源优先级不是绝对排斥国际资料。如果最可靠的原始数据来自国际机构，可以使用；但中国本地事实不应因为搜索方便就默认由外国二手材料代替。

---

# 3. 中国题目的文献结构不能被外国文献“包场”

方法论、经典模型和原始算法可以大量引用高质量国际文献；但涉及以下内容时，应主动检索中文和本土来源：

- 中国政策与制度背景；
- 中国地区、机场、港口、交通、产业和市场现状；
- 国内统计口径；
- 中国行业参数和标准；
- 国内同类问题的应用研究；
- 赛题实体的真实运营背景。

参考文献结构应服务证据，而不是追求“国际化”。

如果最终论文几乎全部是外国文献，而题目明显属于中国本地现实场景，AI 应主动复查：是否漏掉中国官方统计、中文应用研究、国内标准或本土行业资料。

不要求为了“中文比例”硬塞无关文献。**本土优先解决的是证据适配问题，不是文献数量配额。**

---

# 4. 严禁的补数据方式

禁止：

- 凭常识写一个“合理值”；
- 把模型假设包装成真实统计数据；
- 看到搜索摘要后直接抄一个无法核验的数字；
- 用别的地区/年份数据冒充当前对象；
- 看到“行业通常为 XX–YY”就把中间值当真实数据；
- 自行制造增长率、缺失年份、样本量或分布；
- 用插值、均值填补、模拟数据后不标注其性质；
- 为了让模型能跑而偷偷生成现实观测值；
- 将 synthetic / simulated / assumed 数据写成“实际数据”。

如果必须使用估计、插值、外推或模拟，必须明确标注类型：

```text
OBSERVED_EXTERNAL
INTERPOLATED
EXTRAPOLATED
MODEL_ESTIMATED
ASSUMED
SIMULATED
```

其中只有 `OBSERVED_EXTERNAL` 可以不加限定地称为外部观测数据。

---

# 5. 搜索到数据后必须核验口径

取得数据后不能只看数值，还要确认：

- 发布机构；
- 发布时间 / 统计期；
- 对象和地域范围；
- 指标定义；
- 单位；
- 是否累计值 / 当期值；
- 是否自然年 / 财年 / 航季 / 月度；
- 是否含国内/国际、客运/货运等子口径；
- 是否存在修订值；
- 页面、表格、附件是否与引用数字一致。

同名指标口径不一致时，不能直接拼接。

---

# 6. 外部数据必须留下可追溯记录

每个会影响模型、参数、验证、图表或论文结论的外部数据，至少记录：

| 字段 | 说明 |
|---|---|
| 数据名称 | 具体指标 |
| 对象 | 地区 / 机构 / 设备 / 行业 |
| 发布机构 | 原始来源 |
| 来源 URL | 已实际核验链接 |
| 获取日期 | 实际检索日期 |
| 时间范围 | 数据对应时段 |
| 原始单位 | 来源原单位 |
| 使用单位 | 模型中的单位 |
| 口径说明 | 指标定义与范围 |
| 原始位置 | 网页段落 / 表格 / Sheet / 行列 |
| 清洗转换 | 做了什么处理 |
| 使用问题 | 问题 k / 模型 / 验证 |
| 数据类型 | OBSERVED_EXTERNAL / INTERPOLATED / ... |

本地 Agent 应把下载的原始文件和清洗后数据分开保存，遵循 `competition-collaboration.md` 的工作区规则。

---

# 7. 找不到数据时怎么办

经过合理搜索仍找不到可靠数据时：

1. 明确告诉用户缺什么数据；
2. 说明已搜索哪些权威渠道；
3. 给出可选处理：用户补充、改模型、使用可核验代理变量、做区间/敏感性分析；
4. 如果必须假设，明确标为 `ASSUMED`，并说明假设会影响什么；
5. 不因为“任务必须完成”而制造一个数据值。

如果缺失数据会实质改变路线，应在正式实现前的逐题方案确认阶段与用户讨论。

---

# 8. 与旧题盲测的兼容

`BLIND_BENCHMARK_MODE` 仍然允许搜索真实外部数据。

例如旧题涉及机场运营，可以搜索：

- 民航局或机场官方统计；
- 一般机场运行参数；
- 行业标准和公开数据。

但查询必须避免使用足以定位历史赛题答案的题号、题名、原文片段、附件名、特殊数据组合等。

目标是：**禁止搜答案，不禁止查现实。**

如果搜索真实数据时意外命中该旧题历史论文或完整解答，仍按 `search-mode-policy.md` 标记 `ANSWER_LEAKAGE_DETECTED` 并停止继续读取。

---

# 9. 与文献核验规则的关系

本规范决定“什么时候必须主动找现实数据，以及数据真实性底线”。

`source-verification-policy.md` 决定具体来源、链接、全文和元数据怎样核验。

二者同时生效：

```text
现实数据缺口
→ 主动联网检索
→ 优先本土权威来源
→ 实际打开并核验
→ 记录口径与来源
→ 保存原始数据
→ 清洗/转换另存
→ 模型使用
→ 结果与论文可追溯
```

---

# 10. 最终自检

在每问方案确认、Final Run、参考论文和终稿审核前，检查：

- [ ] 是否存在题面未提供但被当成现实事实使用的数字？
- [ ] 这些数字是否真的有来源？
- [ ] 能否追到具体发布机构和原始页面/文件？
- [ ] 单位和统计口径是否一致？
- [ ] 中国现实场景是否优先检索了中国官方/本土资料？
- [ ] 外国文献是否主要用于其真正擅长的方法论/国际证据，而不是替代本土事实？
- [ ] 假设、插值、估计、模拟是否明确标注？
- [ ] 找不到数据时是否诚实报告，而不是补一个值？

任何关键现实数据无法说明来源时，不得把相关结果当作已验证最终结论。
