## 1. 输入完整性检查

确认是否获得完整题面、所有附件、字段说明、单位、输出格式、比赛规则、队伍已有思路、可用软件、时间和成员能力。

缺失内容分为：

- 阻塞性缺失：不补充就无法可靠分析；
- 可假设缺失：可以在明确假设下继续；
- 非关键缺失：不影响当前路线选择。

不得偷偷推测缺失附件内容。

## 2. 逐句读题

建立“题面事实表”：

| 类别 | 内容 |
|---|---|
| 明确事实 | 题面直接给出的事实 |
| 要求动作 | 评价、预测、解释、优化、设计、检验等 |
| 输出对象 | 指标、排序、预测值、方案、路径、策略等 |
| 约束 | 容量、时间、预算、物理规律、规则等 |
| 时间尺度 | 时点、日、月、年、长期 |
| 空间尺度 | 个体、节点、区域、全国等 |
| 不确定项 | 模糊定义、缺失参数、潜在歧义 |
| 禁止外推 | 题面没有支持的范围 |

识别题目动词及验收标准：

- 评价/排序：指标合理性、权重稳健性、排序稳定性；
- 预测：时间切分、误差、区间、不确定性；
- 解释/影响：机制、统计显著性、混杂因素；
- 优化/设计：目标、决策变量、约束、可行性和基线对比；
- 制定策略：场景、风险、可执行性和切换条件；
- 检验：原假设、统计功效、误差类型和稳健性；
- 仿真：状态、规则、参数来源、重复实验和收敛。

## 3. 建立任务图

对每个子问题记录输入、输出、变量、约束、评价标准、前置问题和后续用途。输出依赖图，例如：

`数据清洗 → 特征构造 → 问题一评价 → 问题二预测 → 问题三优化 → 全局验证`

检查循环依赖、结果泄漏和用后文结论反推前文参数。

## 4. 题型识别

每个子问题可以是混合题型：

- 数据描述与异常识别；
- 综合评价与排序；
- 统计推断与因果解释；
- 分类、聚类和识别；
- 时间序列与一般预测；
- 数学规划与组合优化；
- 网络与图论；
- 随机过程与决策；
- 机理模型与微分方程；
- 仿真和情景推演；
- 多目标决策；
- 不确定性、鲁棒性和风险。

## 5. 数据审计

检查样本量、时间跨度、缺失、重复、异常、量纲、编码、时间切分、目标泄漏、未来信息泄漏、多源口径、外部数据、参数来源。输出“数据缺口—影响—替代方案”表。

## 6. 假设系统

每条假设必须包含：

1. 假设内容；
2. 简化了什么；
3. 为什么合理；
4. 可能造成什么偏差；
5. 如何检查。

删除与模型无关的空话，例如“假设数据真实可靠”。

## 7. 候选路线

至少提出：

- 低风险基线；
- 推荐主路线；
- 条件允许时的增强路线。

每条路线给出对应子问题、核心思想、变量、目标、约束、数据要求、求解步骤、验证、优势、局限、失败条件、推荐指数和置信度。

避免伪候选：只换预测器、权重法或求解器，却不改变建模逻辑。

## 8. 首选路线

形成闭环：

`题面事实 → 假设 → 数据 → 变量 → 模型 → 求解 → 结果 → 验证 → 结论`

复杂模型必须有可比较基线。增强模型没有显著贡献时，退回简单模型。

## 9. 验证系统

### 正确性

单位、量纲、边界、约束、数值范围、小样本人工核算。

### 有效性

基线比较、留出或滚动验证、历史案例或外部数据对照、指标与任务一致。

### 稳健性

参数和权重扰动、数据删除或重采样、场景变化、替代模型、随机算法多次运行、最坏情况。

不要只写“结果稳定”，必须给扰动范围、指标变化和判断阈值。

## 10. 文献计划

分别检索背景机制、原始模型、参数范围、数据来源、评价指标、验证方法、相似应用和优秀论文表达结构。给出中英文关键词组合。

## 11. 写作与实现交接

写作主线应让评阅者沿着：

`摘要 → 模型总览图 → 关键结果图表 → 验证 → 结论`

快速复述工作。

不写代码，只输出数据输入、清洗规则、模块输入输出、公式、参数范围、算法类别、中间结果、图表、验收测试和回退方案。
