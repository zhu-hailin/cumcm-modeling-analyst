# 建模证据质量门

## 目标

质量门用于审计已经提出的方案，不用于限制模型想象空间。

```text
QUALITY_GATES_ARE_AUDITORS_NOT_MODEL_SELECTORS
```

先自由分析机制、数据和可能路线，再用本规范排除泄漏、不适用、不可验证或违反现实约束的方案。

每问分别给出：

```text
SCIENTIFIC_VALIDITY = PASS | QUALIFIED | FAIL
CONTEST_TASK_COMPLETION = PASS | FAIL
```

- **科学有效性**：数据、模型、假设、验证和结论强度是否成立；
- **竞赛完成度**：原题要求的分类、预测值、排名、方案、解释或决策是否被直接交付。

证据有限不等于可以省略主答案。除非目标确实不可识别，否则必须给出当前最佳支持答案、证据等级、不确定范围/敏感性和适用条件。

确实不可识别时使用：

```text
NOT_IDENTIFIABLE
```

同时给出能支持到的最强替代结论和补充数据需求，禁止编造答案。

---

## 1. 数据结构识别

正式选模前记录：

```text
DATA_STRUCTURE_IDENTIFIED = true / false
样本单位：
目标变量：
特殊结构：
关键限制：
```

至少检查：

- 成分/比例：非负、总和、零值、闭合效应；
- 时间序列：趋势、季节、自相关、结构突变、时间泄漏；
- 空间：坐标系、距离、邻接、空间相关；
- 网络：节点、边、方向、权重、连通；
- 配对/重复测量：组内相关和不可随意拆分；
- 层级：个体、地区、设备或批次嵌套；
- 排名/等级：次序与等距意义；
- 截尾/删失/故障：观测是否完整；
- 优化：决策变量、资源、守恒、整数性和可行域。

不允许只根据“预测、评价、优化、分类”等关键词套模型。

---

## 2. 数据处理可追溯

所有改变数据的处理记录：

| 处理对象 | 处理前 | 处理后 | 规则 | 题意/统计依据 | 可能影响 |
|---|---:|---:|---|---|---|

必须说明缺失、异常、零值、重复、单位、编码、插值、估计和样本剔除的语义。

禁止：

- 为方便建模随意删样本；
- 先看结果再选择性删除不利数据；
- 把清洗结果写回原始文件；
- 用“完成数据清洗”代替真实规则；
- 把插值、估计、假设或仿真冒充观测数据。

---

## 3. 模型前提与 baseline

每个正式模型记录：

```text
模型名称：
解决哪个题目动作：
关键前提：
前提检查：
不满足时的替代方案：
```

示例检查包括：

- 列联表期望频数与效应量；
- 回归泄漏、残差、共线性与外推范围；
- 时间序列滚动验证而非随机切分；
- 聚类距离、标准化、簇数与重采样稳定性；
- 成分数据零值、变换和逆变换；
- 启发式优化的可行解、停止条件、重复实验和上下界；
- 相关、灰色关联或相似性不得直接写成因果。

每个核心结论保留一个透明 baseline。复杂模型只有在精度、稳定性、可解释性、计算成本或现实约束上提供真实收益时，才有资格成为主模型。

路线明显时不强制比较多个模型；存在真实备选时再进行定量评分。证据不足时允许定性排序。

---

## 4. 分层、变量和验证单位

分层必须回答：

1. 分层前后机制或分布是否确有差异；
2. 统一模型加组别/交互项是否已经足够；
3. 分层后样本量是否仍支持模型；
4. 分层模型在验证中是否更稳定。

变量筛选前先检查尺度、共线性和“距离由谁主导”。禁止为了簇更清楚或图更好看事后挑变量。

训练/验证/测试的切分单位必须与样本生成机制一致。同一主体、设备、地区、时间窗口或重复测量不能被不恰当地拆入不同集合。

---

## 5. 主答案与证据等级

每问先写：

```text
primary_answer：一句话直接答案或 NOT_IDENTIFIABLE
evidence_grade：A | B | C
uncertainty_or_sensitivity：
applicable_conditions：
```

建议含义：

- **A**：主模型证据、独立验证和现实约束均充分；
- **B**：当前数据下结论较稳定，但仍有明显样本、外推或验证限制；
- **C**：只能提供探索性或条件性结论，不能写成确定事实。

A 级核心结论原则上采用：

```text
主模型证据 + 至少一种不同原理的独立验证
```

例如预测 + 滚动验证、启发式解 + 小规模精确解/上下界、排名 + 权重扰动、分类 + 外层分组验证或结构一致性。

同原理模型相互重复不自动构成独立验证。

---

## 6. 现实约束审计

检查题目适用的：

- 非负、上下界、总和和守恒；
- 容量、库存、流量和时间窗；
- 资源冲突、逻辑先后和路径连通；
- 整数性、唯一性和覆盖；
- 概率/成分总和；
- 单位、量纲和业务可执行性。

推荐输出：

| 约束 | 最大违反量 | 是否满足 | 证据文件/代码 |
|---|---:|---|---|

指标很好但现实约束不满足，科学有效性仍为 `FAIL`。

---

## 7. 高风险专项审计

### 完美指标

准确率、F1、拟合优度或其他指标异常接近理论上限时，检查：

- 测试集是否过小；
- 同源样本、重复记录或主体是否跨集合；
- 特征、预处理或调参是否泄漏测试信息；
- 类别不平衡是否掩盖错误；
- 是否只报告有利 seed；
- 多折、多 seed、外层验证或外部数据是否仍成立。

审计前不得把完美指标写成“模型一定正确”。

### 潜在阶段解释

聚类簇、主成分或隐状态被解释为早/中/晚、轻/中/重等阶段时，必须有已知锚点、单调指标、机理、外部标签或多方法稳定顺序。

证据不足时只能称为潜在状态、相似性分组或程度代理。

---

## 8. 跨问题复用

维护：

| 上游问题 | 下游问题 | 复用对象 | 文件/Final Run | 是否重算 | 说明 |
|---|---|---|---|---|---|

后问必须从正式文件和上游 Final Run 读取数据、参数、模型、阈值、分类结果或结论，不能从聊天或论文文字手抄。

上游更新后执行：

```text
上游 Final Run
→ 跨问接口
→ 下游代码与结果
→ 图表
→ 教程
→ 论文证据蓝图
→ 论文
```

---

## 9. 成本—决策价值停止条件

安全审计不因成本取消，但可以按哈希去重。

其他追加验证、搜索或复核继续前记录：

```text
可能改变哪个决策？
通过/失败分别采取什么行动？
预计时间、网络、Token 和磁盘成本？
结果是否已饱和，不会改变主答案或证据等级？
```

不会改变模型、主答案、证据等级或论文边界时停止，避免为了“更严谨”无限堆实验。

---

## 10. 每问完成判定

### 科学有效性

- `PASS`：模型前提、数据、验证、现实约束和结论强度均通过；
- `QUALIFIED`：主结论可用，但必须带明确条件、范围或不确定性；
- `FAIL`：存在泄漏、模型不适用、无法复现、关键约束违反或证据不支持结论。

### 竞赛完成度

只有以下均满足才为 `PASS`：

- 原题每个动作词和交付对象均有直接答案；
- 单位、范围、边界和指定格式明确；
- 主答案没有被限制段落淹没；
- 结果文件、Final Run 和后问接口可定位；
- 无法识别项使用 `NOT_IDENTIFIABLE` 并给出替代结论，而不是留白或编造。

普通失败统一标记：

```text
MODELING_EVIDENCE_GATE_FAILED
```

并指出是科学有效性、竞赛完成度，还是两者同时失败。
